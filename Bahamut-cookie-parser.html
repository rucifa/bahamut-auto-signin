巴哈 Cookie 解析工具

GitHub Secrets 設定說明

1

在 Chrome / Edge 登入巴哈後，按 F12 → Application → Cookies → www.gamer.com.tw，全選複製。

2

將複製的內容貼入上方文字框，按「解析 Cookie」。

3

前往 GitHub Repo → Settings → Secrets and variables → Actions，新增以下 4 個 Secret。

BAHAMUT_COOKIE 本工具解析出的完整 Cookie 字串。
EMAIL_USER 寄信用的 Gmail 地址。
EMAIL_PASS Gmail 應用程式密碼（16 碼）。
EMAIL_TO 收通知信的 Email 地址。

⚠️ Cookie 通常會過期，到期前請重新登入並更新 Secret。此工具完全在本機瀏覽器執行，不傳送資料。
